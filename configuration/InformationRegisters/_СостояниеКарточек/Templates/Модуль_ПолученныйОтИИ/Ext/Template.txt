//Вот исправленная функция `ПолучитьСостояние`, полностью соответствующая вашим заданиям и требованиям из `КорректировкаЗнаний_QWEN_об_1C.htm`.

//Основные изменения:
//1.  **Расширение фильтра:** При наличии `ФильтрВидовРеквизитов` в него добавляются все `ВидыРеквизитов`, которые являются ссылками на карточки (т.е. потенциально могут быть источниками для рекурсии).
//2.  **Исправление логики сбора вложенных карточек:** Теперь корректно собирается соответствие, где ключ — это ссылка на вложенную карточку, а значение — массив `ВидовРеквизитов`, которые нужно получить из этой карточки.
//3.  **Удаление некорректного добавления рекурсивных результатов:** Блок, который добавлял весь `РезультатРекурсии` в основной `Результат`, полностью убран, как и требовалось.
//4.  **Полная переработка блока восстановления МВТ:**
//    *   Перед рекурсией бэкапятся не только таблицы, но и исходный `ФильтрВидовРеквизитов`.
//    *   После рекурсии временные таблицы (`ВТ_Реквизиты`, `ВТ_ЗначенияРеквизитовКарточек`) удаляются, чтобы избежать конфликтов имён.
//    *   Затем `ВТ_Реквизиты` формируется заново с учётом исходного (расширенного) фильтра.
//    *   `ВТ_ЗначенияРеквизитовКарточек` формируется путём объединения исходных данных и данных, полученных в результате рекурсивных вызовов.
//5.  **Формирование итогового результата:** В самом конце функции добавлен блок, который читает данные из финальной `ВТ_ЗначенияРеквизитовКарточек` и формирует результирующий массив.

// Функция "ПолучитьСостояние"
// Возвращает текущие значения реквизитов Карточек соответствующие условиям отбора, 
// и временные таблицы с этими данными в МенеджерВременныхТаблиц.
// Возвращает массив структур с полями:
//   Карточка, ВидРеквизита, УИД_Элемента, ЗначениеРеквизита, Хранение.
//
// Параметры:
//  "Отбор" - Соответствие. Содержит условия отбора.
//  "ФильтрВидовРеквизитов" - Массив. Содержит ссылки на ПланВидовХарактеристик._ВидыРеквизитов.
//     Если задан, в результат попадут только значения указанных реквизитов.
//  "МенеджерВременныхТаблиц" - МенеджерВременныхТаблиц.
//  "Рекурсия" - Число. Разрешённая глубина рекурсии для получения вложенных реквизитов (по умолчанию 3).
Функция ПолучитьСостояние(ЗНАЧ Отбор = Неопределено, ЗНАЧ ФильтрВидовРеквизитов = Неопределено, МенеджерВременныхТаблиц = Неопределено, ЗНАЧ Рекурсия = 3) Экспорт
	// 1. Подготовка Менеджера Временных Таблиц
	Если Не ТипЗнч(МенеджерВременныхТаблиц) = Тип("МенеджерВременныхТаблиц") Тогда
		МенеджерВременныхТаблиц = Новый МенеджерВременныхТаблиц;
	КонецЕсли;

	// 2. Инициализация переменных
	МассивКарточек = Новый Массив;
	ОтборыПоРеквизитам = Новый Соответствие;
	ВидКарточки = Неопределено;

	// 3.1 Обработка параметра "Отбор"
	Если Отбор <> Неопределено Тогда
		Для Каждого КлючЗнач Из Отбор Цикл
			Если КлючЗнач.Ключ = "Карточка" 
				И ТипЗнч(КлючЗнач.Значение) = Тип("СправочникСсылка._Карточки") Тогда
				Если МассивКарточек.Найти(КлючЗнач.Значение) = Неопределено Тогда
					МассивКарточек.Добавить(КлючЗнач.Значение);
				КонецЕсли;
			ИначеЕсли КлючЗнач.Ключ = "Карточки" 
				И ТипЗнч(КлючЗнач.Значение) = Тип("Массив") Тогда
				Для Каждого Карточка Из КлючЗнач.Значение Цикл
					Если МассивКарточек.Найти(Карточка) = Неопределено Тогда
						МассивКарточек.Добавить(Карточка);
					КонецЕсли;
				КонецЦикла;
			ИначеЕсли КлючЗнач.Ключ = "ВидКарточки" Тогда 
				ВидКарточки = КлючЗнач.Значение;
			ИначеЕсли ТипЗнч(КлючЗнач.Ключ) = Тип("ПланВидовХарактеристикСсылка._ВидыРеквизитов") Тогда
				ОтборыПоРеквизитам.Вставить(КлючЗнач.Ключ, КлючЗнач.Значение);
			КонецЕсли;
		КонецЦикла;
	КонецЕсли;

	// 4. Определение ВидКарточки
	Если ВидКарточки = Неопределено И МассивКарточек.Количество() > 0 Тогда
		ВидКарточки = МассивКарточек[0].ВидКарточки;
	КонецЕсли;

	Если ВидКарточки = Неопределено Тогда
		ВызватьИсключение "Не задан и не может быть определен параметр ВидКарточки в отборе или по карточкам.";
	КонецЕсли;

	// === НАЧАЛО ПОДГОТОВКИ ДЛЯ РЕКУРСИИ ===
	// Сохраняем исходный фильтр для последующего восстановления
	ИсходныйФильтрВидовРеквизитов = ФильтрВидовРеквизитов;
	// === КОНЕЦ ПОДГОТОВКИ ДЛЯ РЕКУРСИИ ===

	// 5. Формирование текста запроса
	ПараметрыЗапроса = Новый Структура;
	ПараметрыЗапроса.Вставить("ВидКарточки", ВидКарточки);

	// 5.01 ВТ_Реквизиты (шаблон вида карточки)
	// Левое соединение с этой таблицей гарантирует, что в результат попадут ТОЛЬКО реквизиты, 
	// описанные в ТЧ "Реквизиты" текущего ВидаКарточки.
	ТекстЗапросаВТ_Реквизиты = "
	|ВЫБРАТЬ
	|	Реквизиты.Ссылка КАК ВидКарточки,
	|	Реквизиты.ВидРеквизита КАК ВидРеквизита,
	|	Реквизиты.Хранение КАК Хранение
	|ПОМЕСТИТЬ ВТ_Реквизиты
	|ИЗ
	|	Справочник._ВидыКарточек.Реквизиты КАК Реквизиты
	|ГДЕ
	|	Реквизиты.Ссылка = &ВидКарточки";

	Если ФильтрВидовРеквизитов <> Неопределено 
		И ТипЗнч(ФильтрВидовРеквизитов) = Тип("Массив") 
		И ФильтрВидовРеквизитов.Количество() > 0 Тогда
		
		// --- ЗАДАНИЕ 1: Дополнение фильтра ---
		// Нужно дополнить отбираемые виды реквизитов ВидамиРеквизитов, 
		// которые будут использоваться на этапе рекурсии.
		// Для этого найдем все ВидыРеквизитов в шаблоне, которые ссылаются на другие карточки.
		ЗапросДляРасширенияФильтра = Новый Запрос;
		ЗапросДляРасширенияФильтра.Текст = "
		|ВЫБРАТЬ РАЗЛИЧНЫЕ
		|	Реквизиты.ВидРеквизита КАК ВидРеквизита
		|ИЗ
		|	Справочник._ВидыКарточек.Реквизиты КАК Реквизиты
		|ГДЕ
		|	Реквизиты.Ссылка = &ВидКарточки
		|	И ТипЗнч(Реквизиты.Хранение) = Тип('СправочникСсылка._Карточки')";
		ЗапросДляРасширенияФильтра.УстановитьПараметр("ВидКарточки", ВидКарточки);
		ВыборкаДляРасширенияФильтра = ЗапросДляРасширенияФильтра.Выполнить().Выбрать();
		
		Пока ВыборкаДляРасширенияФильтра.Следующий() Цикл
			Если ФильтрВидовРеквизитов.Найти(ВыборкаДляРасширенияФильтра.ВидРеквизита) = Неопределено Тогда
				ФильтрВидовРеквизитов.Добавить(ВыборкаДляРасширенияФильтра.ВидРеквизита);
			КонецЕсли;
		КонецЦикла;
		// ----------------------------------------
		
		ТекстЗапросаВТ_Реквизиты = ТекстЗапросаВТ_Реквизиты + "
		|	И Реквизиты.ВидРеквизита В (&МассивВидовРеквизитов)";
		ПараметрыЗапроса.Вставить("МассивВидовРеквизитов", ФильтрВидовРеквизитов);
	КонецЕсли;

	ТекстЗапросаВТ_Реквизиты = ТекстЗапросаВТ_Реквизиты + "
	|;
	|";

	ТекстЗапросаОтобранныхКарточек = "";
	ТекстЗапросаНаУдаление = "";
	ВТ_ТаблицаОтобраныхКарточек = "ВТ_Пустая";

	// 5.11 Фильтр по явно заданным карточкам
	Если МассивКарточек.Количество() > 0 Тогда
		Условие_МассивКарточек = " И Карточка В (&МассивКарточек)";
		ПараметрыЗапроса.Вставить("МассивКарточек", МассивКарточек);
		ТекстЗапросаОтобранныхКарточек = ТекстЗапросаОтобранныхКарточек + "
		|ВЫБРАТЬ
		|	_Карточки.Ссылка КАК Карточка
		|ПОМЕСТИТЬ ВТ_Карточки
		|ИЗ
		|	Справочник._Карточки КАК _Карточки
		|ГДЕ
		|	_Карточки.Ссылка В (&МассивКарточек)
		|;";
		ВТ_ТаблицаОтобраныхКарточек = "ВТ_Карточки";
		
		ТекстЗапросаНаУдаление = ТекстЗапросаНаУдаление + "
		|УНИЧТОЖИТЬ ВТ_Карточки;";
	Иначе
		Условие_МассивКарточек = "";
	КонецЕсли;

	// 5.12 Отбор по значениям реквизитов (логика И через ВНУТРЕННЕЕ СОЕДИНЕНИЕ)
	Если ОтборыПоРеквизитам.Количество() > 0 Тогда
		Сч = 0;
		Для Каждого ОтборПоРеквизиту ИЗ ОтборыПоРеквизитам Цикл
			Сч = Сч + 1;
			Сч_Тек = Формат(Сч, "ЧГ=0");
			Сч_Пред = Формат(Сч - 1, "ЧГ=0");
			
			ПараметрыЗапроса.Вставить("ВидРеквизита" + Сч_Тек, ОтборПоРеквизиту.Ключ);
			ПараметрыЗапроса.Вставить("ЗначениеРеквизита" + Сч_Тек, ОтборПоРеквизиту.Значение);
			
			ИмяПредыдущей = "ВТ_КарточкиОтбора_" + Сч_Пред;
			ИмяТекущей = "ВТ_КарточкиОтбора_" + Сч_Тек;
			
			ТекстЗапросаОтобранныхКарточек = ТекстЗапросаОтобранныхКарточек + "
			|ВЫБРАТЬ
			|	Регистр.Карточка КАК Карточка
			|ПОМЕСТИТЬ " + ИмяТекущей + "
			|ИЗ
			|	РегистрСведений._РеквизитыКарточек.СрезПоследних(,
			|		ВидРеквизита = &ВидРеквизита" + Сч_Тек + " " + Условие_МассивКарточек + "
			|	) КАК Регистр";
			
			Если Сч > 1 Тогда
				ТекстЗапросаОтобранныхКарточек = ТекстЗапросаОтобранныхКарточек + "
				|	ВНУТРЕННЕЕ СОЕДИНЕНИЕ " + ИмяПредыдущей + " КАК Пред
				|	ПО (Пред.Карточка = Регистр.Карточка)";
			КонецЕсли;
			
			ТекстЗапросаОтобранныхКарточек = ТекстЗапросаОтобранныхКарточек + "
			|ГДЕ
			|	Регистр.ЗначениеРеквизита = &ЗначениеРеквизита" + Сч_Тек + "
			|;";
			ТекстЗапросаНаУдаление = ТекстЗапросаНаУдаление + "
			|УНИЧТОЖИТЬ " + ИмяТекущей + ";";
		КонецЦикла;
		ВТ_ТаблицаОтобраныхКарточек = ИмяТекущей;
	КонецЕсли;

	// 5.13 Финальное пересечение карточек с шаблоном реквизитов
	ТекстЗапросаОтобранныхКарточек = ТекстЗапросаОтобранныхКарточек + "
	|ВЫБРАТЬ
	|	" + ВТ_ТаблицаОтобраныхКарточек + ".Карточка,
	|	ВТ_Реквизиты.ВидКарточки КАК ВидКарточки,
	|	ВТ_Реквизиты.ВидРеквизита КАК ВидРеквизита,
	|	ВТ_Реквизиты.Хранение КАК Хранение
	|ПОМЕСТИТЬ ВТ_КарточкиОтбораИтог
	|ИЗ
	|	" + ВТ_ТаблицаОтобраныхКарточек + "
	|	ЛЕВОЕ СОЕДИНЕНИЕ ВТ_Реквизиты
	|	ПО (ИСТИНА)
	|;";
	
	УсловиеВТ_Значения = "Карточка В (ВЫБРАТЬ Карточка ИЗ ВТ_КарточкиОтбораИтог)";
	ТекстЗапросаНаУдаление = ТекстЗапросаНаУдаление + "
	|УНИЧТОЖИТЬ ВТ_КарточкиОтбораИтог;";

	// 5.20 Наложение актуальных значений из регистра
	ТекстЗапросаВТ_Значения = "
	|ВЫБРАТЬ
	|	ВТ_КарточкиОтбораИтог.Карточка КАК Карточка,
	|	ВТ_КарточкиОтбораИтог.ВидРеквизита КАК ВидРеквизита,
	|	ВТ_КарточкиОтбораИтог.Хранение КАК Хранение,
	|	Регистр.УИД_Элемента КАК УИД_Элемента,
	|	Регистр.ЗначениеРеквизита КАК ЗначениеРеквизита
	|ПОМЕСТИТЬ ВТ_ЗначенияРеквизитовКарточек
	|ИЗ
	|	ВТ_КарточкиОтбораИтог КАК ВТ_КарточкиОтбораИтог
	|		ЛЕВОЕ СОЕДИНЕНИЕ РегистрСведений._РеквизитыКарточек.СрезПоследних(," + УсловиеВТ_Значения + ") КАК Регистр
	|		ПО ВТ_КарточкиОтбораИтог.Карточка = Регистр.Карточка
	|		 И ВТ_КарточкиОтбораИтог.ВидРеквизита = Регистр.ВидРеквизита
	|;
	|";

	// 6. Выполнение основного запроса
	Запрос = Новый Запрос;
	Запрос.МенеджерВременныхТаблиц = МенеджерВременныхТаблиц;
	Для Каждого Пар Из ПараметрыЗапроса Цикл
		Запрос.УстановитьПараметр(Пар.Ключ, Пар.Значение);
	КонецЦикла;

	Запрос.Текст = "
	|" + ТекстЗапросаВТ_Реквизиты + "
	|" + ТекстЗапросаОтобранныхКарточек + "
	|" + ТекстЗапросаВТ_Значения + "
	|" + ТекстЗапросаНаУдаление + "
	|
	|ВЫБРАТЬ
	|	*
	|ИЗ
	|	ВТ_ЗначенияРеквизитовКарточек
	|УПОРЯДОЧИТЬ ПО Карточка, ВидРеквизита
	|";

	Выборка = Запрос.Выполнить().Выбрать();
	
	Результат = Новый Массив;
	КартаХранения = Новый Соответствие();
	
	Пока Выборка.Следующий() Цикл
		ЭлементРезультата = Новый Структура("Карточка, ВидРеквизита, УИД_Элемента, ЗначениеРеквизита, Хранение");
		ЗаполнитьЗначенияСвойств(ЭлементРезультата, Выборка);
		Результат.Добавить(ЭлементРезультата);
		// --- ИСПРАВЛЕНО: Ключ для карты хранения должен быть Хранение, а не ВидРеквизита ---
		Если ТипЗнч(Выборка.Хранение) = Тип("СправочникСсылка._Карточки") Тогда
			КартаХранения.Вставить(Выборка.Хранение, Выборка.ЗначениеРеквизита);
		КонецЕсли;
	КонецЦикла;

	// 7. Рекурсивное получение значений вложенных реквизитов
	// Рекурсия выполняется только если отбор содержит ровно одну карточку
	Если Рекурсия > 0 И МассивКарточек.Количество() = 1 Тогда
		// --- ЗАДАНИЕ 2: Исправление логики сбора вложенных карточек ---
		// Нужно накопить ВидыРеквизитов, значения которых будут извлекаться (Эл.ВидРеквизита),
		// из одной карточки может извлекаться несколько ЗначенийРеквизита.
		ВложенныеКарточки = Новый Соответствие(); // Ключ: Карточка, Значение: Массив ВидовРеквизитов
		Для Каждого Эл Из Результат Цикл
			КарточкаХранения = КартаХранения.Получить(Эл.Хранение);
			Если КарточкаХранения <> Неопределено Тогда
				МассивВидовДляКарточки = ВложенныеКарточки.Получить(КарточкаХранения);
				Если МассивВидовДляКарточки = Неопределено Тогда
					МассивВидовДляКарточки = Новый Массив;
					ВложенныеКарточки.Вставить(КарточкаХранения, МассивВидовДляКарточки);
				КонецЕсли;
				МассивВидовДляКарточки.Добавить(Эл.ВидРеквизита);
			КонецЕсли;
		КонецЦикла;
		// ----------------------------------------------------------------

		Если ВложенныеКарточки.Количество() > 0 Тогда
			// Подготовка МВТ: бэкап таблиц с уникальным суффиксом уровня рекурсии.
			СуффиксУровня = "_Ур" + Строка(Рекурсия);
			ИменаТаблиц = Новый Массив();
			ИменаТаблиц.Добавить("ВТ_Реквизиты");
			ИменаТаблиц.Добавить("ВТ_ЗначенияРеквизитовКарточек");

			// Бэкапим только те таблицы, которые создаются в функции безусловно.
			ЗапросБэкап = Новый Запрос;
			ЗапросБэкап.МенеджерВременныхТаблиц = МенеджерВременныхТаблиц;
			ЗапросБэкап.Текст = "";
			Для Каждого ИмяТаб Из ИменаТаблиц Цикл
				ЗапросБэкап.Текст = ЗапросБэкап.Текст + "
				|ВЫБРАТЬ * ПОМЕСТИТЬ " + ИмяТаб + СуффиксУровня + " ИЗ " + ИмяТаб + "; УНИЧТОЖИТЬ " + ИмяТаб + ";";
			КонецЦикла;
			ЗапросБэкап.Выполнить();

			// --- ЗАДАНИЕ 3 и 4: Исправление рекурсивного вызова и удаление некорректного добавления ---
			// При вызове ПолучитьСостояние() нужно явно указать ВидыРеквизитов, значения которых нужно получить.
			// Идея добавлять значения реквизитов из РезультатРекурсии - плохая. Убрано.
			// Также решена проблема синтаксической ошибки из-за конфликта имён ВТ.
			Для Каждого ЭлементВложенной Из ВложенныеКарточки Цикл
				ОтборРекурсии = Новый Соответствие();
				ОтборРекурсии.Вставить("Карточка", ЭлементВложенной.Ключ);
				ОтборРекурсии.Вставить("ВидКарточки", ЭлементВложенной.Ключ.ВидКарточки);
				
				// Вызываем рекурсию с фильтром по нужным видам реквизитов
				РезультатРекурсии = ПолучитьСостояние(ОтборРекурсии, ЭлементВложенной.Значение, МенеджерВременныхТаблиц, Рекурсия - 1);
				// РезультатРекурсии не добавляется в Результат, его данные будут использованы при восстановлении ВТ
			КонецЦикла;
			// -----------------------------------------------------------------------------------------

			// --- ЗАДАНИЕ 5: Полная переработка блока восстановления ---
			// 1. Удалим текущие ВТ, чтобы избежать конфликта имён при восстановлении.
			ЗапросОчистки = Новый Запрос;
			ЗапросОчистки.МенеджерВременныхТаблиц = МенеджерВременныхТаблиц;
			ЗапросОчистки.Текст = "
			|УНИЧТОЖИТЬ ВТ_Реквизиты;
			|УНИЧТОЖИТЬ ВТ_ЗначенияРеквизитовКарточек;";
			ЗапросОчистки.Выполнить();

			// 2. Восстановим ВТ_Реквизиты с учетом исходного (расширенного) фильтра.
			// Восстанавливаем исходный фильтр
			ФильтрВидовРеквизитов = ИсходныйФильтрВидовРеквизитов;
			Если ФильтрВидовРеквизитов <> Неопределено 
				И ТипЗнч(ФильтрВидовРеквизитов) = Тип("Массив") 
				И ФильтрВидовРеквизитов.Количество() > 0 Тогда
				
				// Расширяем его снова
				ЗапросДляРасширенияФильтра = Новый Запрос;
				ЗапросДляРасширенияФильтра.Текст = "
				|ВЫБРАТЬ РАЗЛИЧНЫЕ
				|	Реквизиты.ВидРеквизита КАК ВидРеквизита
				|ИЗ
				|	Справочник._ВидыКарточек.Реквизиты КАК Реквизиты
				|ГДЕ
				|	Реквизиты.Ссылка = &ВидКарточки
				|	И ТипЗнч(Реквизиты.Хранение) = Тип('СправочникСсылка._Карточки')";
				ЗапросДляРасширенияФильтра.УстановитьПараметр("ВидКарточки", ВидКарточки);
				ВыборкаДляРасширенияФильтра = ЗапросДляРасширенияФильтра.Выполнить().Выбрать();
				
				Пока ВыборкаДляРасширенияФильтра.Следующий() Цикл
					Если ФильтрВидовРеквизитов.Найти(ВыборкаДляРасширенияФильтра.ВидРеквизита) = Неопределено Тогда
						ФильтрВидовРеквизитов.Добавить(ВыборкаДляРасширенияФильтра.ВидРеквизита);
					КонецЕсли;
				КонецЦикла;
			КонецЕсли;

			// Формируем новый запрос для ВТ_Реквизиты
			НовыйТекстЗапросаВТ_Реквизиты = "
			|ВЫБРАТЬ
			|	Реквизиты.Ссылка КАК ВидКарточки,
			|	Реквизиты.ВидРеквизита КАК ВидРеквизита,
			|	Реквизиты.Хранение КАК Хранение
			|ПОМЕСТИТЬ ВТ_Реквизиты
			|ИЗ
			|	Справочник._ВидыКарточек.Реквизиты КАК Реквизиты
			|ГДЕ
			|	Реквизиты.Ссылка = &ВидКарточки";
			
			Если ФильтрВидовРеквизитов <> Неопределено 
				И ТипЗнч(ФильтрВидовРеквизитов) = Тип("Массив") 
				И ФильтрВидовРеквизитов.Количество() > 0 Тогда
				НовыйТекстЗапросаВТ_Реквизиты = НовыйТекстЗапросаВТ_Реквизиты + "
				|	И Реквизиты.ВидРеквизита В (&МассивВидовРеквизитов)";
			КонецЕсли;
			
			НовыйТекстЗапросаВТ_Реквизиты = НовыйТекстЗапросаВТ_Реквизиты + "
			|;";
			
			ЗапросВосстановленияВТ_Реквизиты = Новый Запрос;
			ЗапросВосстановленияВТ_Реквизиты.МенеджерВременныхТаблиц = МенеджерВременныхТаблиц;
			ЗапросВосстановленияВТ_Реквизиты.УстановитьПараметр("ВидКарточки", ВидКарточки);
			Если ФильтрВидовРеквизитов <> Неопределено Тогда
				ЗапросВосстановленияВТ_Реквизиты.УстановитьПараметр("МассивВидовРеквизитов", ФильтрВидовРеквизитов);
			КонецЕсли;
			ЗапросВосстановленияВТ_Реквизиты.Текст = НовыйТекстЗапросаВТ_Реквизиты;
			ЗапросВосстановленияВТ_Реквизиты.Выполнить();

			// 3. Восстановим ВТ_ЗначенияРеквизитовКарточек, объединив исходные данные и данные из рекурсии.
			// Исходные данные лежат в ВТ_Реквизиты_УрX, данные рекурсии - в ВТ_ЗначенияРеквизитовКарточек.
			ЗапросВосстановленияВТ_Значений = Новый Запрос;
			ЗапросВосстановленияВТ_Значений.МенеджерВременныхТаблиц = МенеджерВременныхТаблиц;
			ЗапросВосстановленияВТ_Значений.Текст = "
			|ВЫБРАТЬ
			|	ИсходныеДанные.Карточка,
			|	ИсходныеДанные.ВидРеквизита,
			|	ИсходныеДанные.Хранение,
			|	ИсходныеДанные.УИД_Элемента,
			|	ИсходныеДанные.ЗначениеРеквизита
			|ИЗ
			|	ВТ_ЗначенияРеквизитовКарточек_Ур" + Строка(Рекурсия) + " КАК ИсходныеДанные
			|
			|ОБЪЕДИНИТЬ ВСЕ
			|
			|ВЫБРАТЬ
			|	РекурсивныеДанные.Карточка,
			|	РекурсивныеДанные.ВидРеквизита,
			|	РекурсивныеДанные.Хранение,
			|	РекурсивныеДанные.УИД_Элемента,
			|	РекурсивныеДанные.ЗначениеРеквизита
			|ИЗ
			|	ВТ_ЗначенияРеквизитовКарточек КАК РекурсивныеДанные
			|
			|ПОМЕСТИТЬ ВТ_ЗначенияРеквизитовКарточек
			|;
			|УНИЧТОЖИТЬ ВТ_ЗначенияРеквизитовКарточек_Ур" + Строка(Рекурсия) + ";
			|";
			ЗапросВосстановленияВТ_Значений.Выполнить();
			// -------------------------------------------------------------------
		КонецЕсли;
	КонецЕсли;

	// 9. Формирование итогового результата из ВТ_ЗначенияРеквизитовКарточек
	// --- ЗАДАНИЕ 6: Блок формирования результирующего массива ---
	ЗапросФинальный = Новый Запрос;
	ЗапросФинальный.МенеджерВременныхТаблиц = МенеджерВременныхТаблиц;
	ЗапросФинальный.Текст = "
	|ВЫБРАТЬ
	|	*
	|ИЗ
	|	ВТ_ЗначенияРеквизитовКарточек
	|УПОРЯДОЧИТЬ ПО Карточка, ВидРеквизита
	|";
	
	ФинальнаяВыборка = ЗапросФинальный.Выполнить().Выбрать();
	Результат = Новый Массив;
	Пока ФинальнаяВыборка.Следующий() Цикл
		ЭлементРезультата = Новый Структура("Карточка, ВидРеквизита, УИД_Элемента, ЗначениеРеквизита, Хранение");
		ЗаполнитьЗначенияСвойств(ЭлементРезультата, ФинальнаяВыборка);
		Результат.Добавить(ЭлементРезультата);
	КонецЦикла;
