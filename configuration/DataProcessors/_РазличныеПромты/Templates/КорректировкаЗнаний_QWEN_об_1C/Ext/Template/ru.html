2. Удаление из таблицы значений:
Удалять элементы нужно "с конца". Но в 1С 8.3. отсутствует возможность организовать обратный цикл (от больших элементов к меньшим).
Поэтому нужно получать элементы по выражению ПервоначальноеКоличество - Итератор.
Пример кода с корректным удалением из таблицы значений:
ПервоначальноеКоличествоЭлементов = ТаблицаЗначений.Количество();
...; 
Для Итератор=1 по ПервоначальноеКоличествоЭлементов  Цикл
УдаляемыйЭлемент =Список[ПервоначальноеКоличествоЭлементов - Итератор];
Список.Удалить(УдаляемыйЭлемент);
